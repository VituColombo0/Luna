Reconhecimento Facial da Luna
==============================

Para que a Luna identifique os membros pela camera, crie uma
subpasta para cada pessoa com fotos do rosto:

Estrutura:
  data/faces/
    Victor Vieira Colombo/
      foto1.jpg
      foto2.jpg
    Mario Guerrero Cerconvis/
      foto1.jpg
    Mario Alexandre Gazziro/
      foto1.jpg

Dicas:
- Use pelo menos 2-3 fotos por pessoa
- Fotos com boa iluminacao funcionam melhor
- A face deve estar visivel e centralizada
- Formatos aceitos: .jpg, .jpeg, .png, .webp

Os nomes das subpastas devem corresponder aos nomes
no arquivo Membros.txt para que a Luna carregue as
informacoes corretas de cada pessoa.
